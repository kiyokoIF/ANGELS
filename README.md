# ANGELS
A series of sacred musical objects to find god. 

Like Simone Weil and Rilke, I am in search of impossible beauty. For to consume is to destroy. To desire is to enforce infinite separation. Only god can cross this distance. All we can do is wait. These instruments are my prayer, my turning towards god. For there is no heaven or hell, only infinite now.

### ANGEL_001
This angel forces the user to play it with their hands held in prayer. To release pressure is to drop the object, we are forced to hold our attention `en hypomene` like Weil. The goal is to overwhelm the user with options and controls to induce a state of divine inspiration to heighten this feeling of `hypomene`.
